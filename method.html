Method

Fewer voices. More evidence.

One question, one series. The desk collects the print and what is pushing it. Six ballots vote. The number is the median.

  1. 01

    Download

    US CPI comes from the BLS public API. Eurozone HICP comes from the ECB, which republishes Eurostat. The print, the prior month, and the main components are on the board before anyone votes. A row the feed did not return is a gap.

  2. 02

    Sort

    The Aggregator files each row as official, component, commodity, liquidity, positioning, or event. The Tagger marks it direct, context, or background, and names the event it belongs to.

  3. 03

    Archive

    The Archivist appends those rows to a named series. A point can only be a figure that was already collected. The series is what the voters see, not a fresh pile.

  4. 04

    Vote

    Six workers run in parallel and cannot see each other: Analyst, Skeptic, Quant, Historian, Contrarian, and Scholar. Scholar reads the behavioral and social reading of the same series. A vote that cites a figure off the board is pulled toward 50.

  5. 05

    Score and speak

    The published number is the median. The speaker writes the sentence and cannot move it. An occupied call is not rewritten. The day's median is labeled a desk reading.

  6. 06

    Chief of Staff

    After the run, one officer names the weakest stage and writes the next search order. That order is what the Scout must follow tomorrow. It does not get to edit the code or assume a conclusion.

The six votes

  • AnalystWeight official data and base rates. Distrust narrative. If the print is not in the board, say so.
  • SkepticName how the question could resolve no even if the story is right. Watch revisions, definitions, and timing.
  • QuantStart from what prices, spreads, vols, or betting markets already imply. If none are in the board, say the board is thin and stay near 50.
  • HistorianUse the closest precedent in the board. If there is no analogue, say so rather than inventing one.
  • ContrarianIdentify a neglected mechanism, not the reflexive opposite. Move far from 50 only when that mechanism is concrete in the evidence.
  • ScholarRead the same series for behavior: positioning, fear, habit. If none of that is on the board, stay near 50.

What scales

Workers are pure functions of the evidence board. They hold no memory of each other, so the fan-out can grow without a longer chain. The speaker always reads structured ballots, not transcripts.

Resolution is a separate search against criteria that were written first. A draft verdict stays off the public record until a person accepts it on the Desk. Nothing resolves itself.

Coverage is unchanged: macro, capital markets, crypto, geopolitics and policy, frontier AI and energy.
